# Connected Google Drive versus GC Equity: source reconciliation

**Updated:** 23 November 2026. **Comparison basis:** The two user-supplied "Full report with sizes, Drive links and where each one goes" attachments used GitHub commit `5a831176` as their baseline. That baseline predates the changes summarized below. This register reports work actually committed to the main branch, and distinguishes hosting source files from using them in a chart or analysis.

## Sources restored and available in the public repository

1. **38 original, bilingual 2013–2014 TBS employment-equity XLS workbooks** (19 tables, English and French; 1,728,512 bytes). Original workbook bytes and worksheet structures preserved. Includes representation, salary, employment type, hiring, promotions and separations. These were originally recovered from Wayback Machine snapshots because the live publisher links were dead. See `data/open-canada-2026-11/tbs-ee-annual-report-2013-2014/manifest.json` for every size and Git blob identifier. The site offers each original downloadable file at `reports.html#tbs-2013-2014-historical-tables`. Historic definitions must not be merged with present-day departments or workforce availability.
2. **Six original 2010–2026 TBS department-level population CSVs** missing from the original source folder (age bands, sex and first official language, each in English and French). The existing suppression-aligned derivatives remain separate for bilingual presentation. The original French CSVs were fetched through a text interface and retain values but were re-encoded to UTF-8.
3. **2018 Staffing and Non-Partisanship Survey department dataset**: all 27,316 source rows in 16 files under `data/open-canada-2026-11/snps-2018-by-department-parts/`. `manifest.json` records row totals, per-part SHA256, source and original file details. The exact source row text and order are preserved. Download links added to `reports.html#snps-2018-department-complete`. This is survey response evidence, not appointment administration data.
4. **PSC FY2026–2027 advertisements**: replaced stale 1,615-row original with the newer 2,429-row Drive version at its original hosted path. This is a source refresh, not a change to equity group-specific outcomes.
5. **Employer equity data added and linked**: the previous November 23 batch of 30 public CSVs for DND civilians, Communications Security Establishment, Canadian Security Intelligence Service, Veterans Affairs and Canada School of Public Service. **Fourteen further original XLSX workbooks** for DND civilian equity/gender (4), VAC occupation-specific data (2), CSPS original annual data and dictionary (8) were subsequently added without modifying the binary content. Each source is linked from the bilingual `reports.html` catalogue and remains scoped to its specific employer.
6. **PSES smaller source workbooks**: original 2019 diversity/inclusion tables (155,217 bytes), 2022–2023 result tables (1,077,128 bytes), 2024 employment-equity result tables (2,519,548 bytes), and 2024 supporting documentation (483,682 bytes) are now hosted and linked. They remain separate from full respondent-level extracts.
7. **Austerity tool**: supplemental bilingual source-based panel, worked percentages, illustrative equity-group and region calculations, peer comparison, absolute-number and target inputs, PBO and Budget 2025 context, disclosure cautions, guided discussion questions, new action templates, hypothetical CSV status and sitemap entry. The supplemental code is not a forecast and is not verified through a full interactive browser session.
8. **Integrity automation**: `.github/workflows/update-source-checksums.yml` regenerates `data/checksums.sha256` after data changes. First workflow execution succeeded on 23 November 2026 and committed the new register. Regression checks cover 30 original employer CSVs, 14 original workbooks, the 38 historical TBS files and source links.

## Source decisions still open or excluded

- **PSES 2024 subsets 2–7 plus historical subset 4:** Drive retains the original files, ranging from about 529 MB to 1.76 GB each, totaling more than 6 GB. They cannot be published whole through ordinary GitHub source hosting; a lossless privacy-safe, source-versioned partition and browser-sized indexing plan is still required. Smaller PSES-derived and departmental extracts currently on the site do not prove complete coverage of all original source rows. The historical 2024 subset 4 is on Drive; earlier notes saying its upload failed are obsolete.
- **Full large PSES source files** `EEINFODV.csv`, `EELEVEL2ID.csv`, `main-principal.csv`, `HRINFO.csv` and the unidentified loose 1.08 GB root CSV remain unverified at exact-source completeness level. Encoded extracts on the site are not automatically equivalent to original files; compare contents, source provenance and disclosure rules, not filenames alone.
- **PSES 2018, 2019 and 2020 supporting documentation XLSX files** are still not hosted under their original names (approximately 6.2–6.4 MB each). A raw binary upload exceeded the connected GitHub interface's reliable request size; do not claim they were uploaded. The 2019 diversity result workbook has been hosted, however.
- **PSC FSWEP referrals** November 5, 2026 snapshot (30,887,309 bytes, 72,822 rows) still requires versioned incorporation. The current hosted snapshot from October 2 contains fewer rows; public reporting and self-identification flags require careful disclosure handling.
- **PSES/SNPS staging:** the 158 precomputed occupation chunks for 2018 and 2021 SNPS exist in separate staging; original survey releases are already represented as source or encoded data. Do not call the staged packaging itself a new survey dataset. The 2024 PSES large-file source-partitioning remains substantive.
- **PSC staffing-dashboard priority appointments** 7,447-byte CSV, **CSIS 2019 pay scales** and **June 2022 vaccination/accommodation status** have not been placed into core employment-equity outcomes, because their populations/variables require separate context. The PSC file is a candidate for a clearly labeled administrative staffing source, not for an equity representation denominator.
- **Statistics Canada national wages by occupation**, ~80.9 MB compressed/1.66 GB decompressed, and **ESDC federally regulated private-sector LEEP benchmarks** are not federal public-service employee or departmental salary-equity datasets. Keep these external comparators separate from departmental measures; do not import them as federal public-service counts.
- **OLRRE official-languages office-obligations file** remains out of the core workforce-equity data scope pending an explicit policy/office-context use case.
- **October 2026 Drive site/source archives** and ARAN resource library folders were inventoried at folder level. Archive packages are not new data by themselves. Public research/policy documents may support a separate curated resource library but are not safe to bulk-publish without license, access and scope review.
- **Small content mismatches in the 73-file public-source CSV archive** (including Indigenous and disability subgroup datasets) require source-level checksum/row comparison to verify transformation versus error. Filename and file-size matches are not sufficient. The historical snapshot `assets/data-coverage-audit.json` is not a current exhaustive Drive-source manifest.

## Acceptance rules and what is not yet certified

- Public source, reporting universe, institution, group definition, period, respondent base and suppression rule travel with each file and each analysis.
- The original bilingual Excel sources are downloadable, but a chart/search interface reading their internal worksheets has not been built. Hosted files and searchable analytical tables are different completion states.
- Reconstruct neither suppressed counts nor headcounts from rounded group percentages. Overlapping groups cannot be added to compute overall staffing effects.
- Full PSES raw ingestion, the latest FSWEP snapshot, three large PSES supporting workbooks, file-level reconciliation of the October archive, and **live browser accessibility and French interaction testing** are still outstanding.
- A GitHub commit or checksum refresh alone is not a passed site validation. Check **GC Equity site validation**, **desktop/mobile smoke** and **Pages deployment** workflows on the latest main branch before certifying release.
- Do not claim there are no unexamined folders or file versions outside the returned accessible Google Drive listing. This audit is scoped to the Drive holdings exposed through the connected account and the specifically named public source collections.

**Summary:** Major source gaps from the user's November 22 baseline have been resolved and the exact 2013–14 XLS collection, original DND/VAC/CSPS workbooks and smaller PSES methodology files are now hosted. Complete raw PSES 2024 and updated FSWEP ingestion remain open, with further end-to-end validation required.
